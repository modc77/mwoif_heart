# คู่มือ UI ส่งใจ V1

## เป้าหมาย

UI ต้องใช้งานได้บนหน้าจอเล็กโดยไม่ต้องเปิด CMD และไม่ต้องสร้างไฟล์ Session/Auth เอง

## เพิ่มไอดีส่ง

1. กด `+ เพิ่มไอดีส่ง`
2. ช่องไอดีจะเลือกเลขถัดไปให้อัตโนมัติ
3. Copy Session จาก LAB แล้วกด `วางจากคลิปบอร์ด`
4. Copy Auth Context จาก LAB แล้วกด `วางจากคลิปบอร์ด`
5. กด `บันทึก + ไอดีถัดไป` เมื่อต้องเพิ่มหลายไอดี

## ตัวรับหลัก

กด `ตั้งค่าตัวรับ` แล้ววาง Session/Auth แบบเดียวกัน

## หน้าจอเล็ก

- หน้า `ส่งใจ` ใช้ layout แนวตั้ง ไม่แบ่งซ้าย/ขวา
- Log แยกเป็นแท็บ `บันทึก`
- ตารางมี scrollbar แนวนอน/แนวตั้ง
- ขนาดหน้าต่างเริ่มตามความละเอียดหน้าจอ
